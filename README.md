# Sistema de gestión de solicitudes

Trabajo práctico integrador (UTN) — PHP + MySQL, sin frameworks.
Formulario público de solicitudes de soporte y panel administrativo con login, listado,
filtro por estado, detalle y cambio de estado.

> 🚧 En desarrollo. Requisitos, instalación y ejecución se completan al cerrar la implementación.
